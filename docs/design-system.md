# CargoFlow Design System — системное приложение Apple

CargoFlow выглядит и ведёт себя как системное приложение macOS/iOS (Mail, Finder, Maps, Settings, Wallet), а не как
лендинг или шаблонная SaaS-панель. Плотность — как у Mail и Finder, а не как у apple.com. Цвет обозначает только
состояние объекта и главное действие. Группы отделяются волосяными линиями, тени есть только у плавающих
поверхностей. Светлая и тёмная темы переключаются по системе.

Источник истины — `src/app/globals.css` (токены, роли, материалы) и `src/components/**` (компоненты).

## Раскладка

| Экран                   | Где                                                            | Устройство                                                                                                                                                                                                                             |
| ----------------------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| Три колонки, как в Mail | `/dashboard`, `/orders`, `/vehicles` (`SplitView`)             | список 352 px слева, справа карта и детали выбранного объекта; без выбора — обзорная карта. `?selected=` в адресе, Esc закрывает. | Формы                   | вход, регистрация (`FormGroup`/`FormRow`), остальные (`Field`) | как окно Apple ID и iOS Settings: строки «подпись — поле» в одном блоке; `Field layout="row"` — подпись слева на широком экране                                                                                                        |
| Водитель                | `/driver/**`                                                   | iOS-приложение: крупный заголовок, карточка рейса в стиле посадочного талона Wallet, одна главная кнопка, быстрые действия как в Картах                                                                                                |

## Цвет

Системные цвета HIG парами светлый/тёмный (`@media (prefers-color-scheme: dark)`). Текст на фоне — не ниже 4.5:1 в обеих темах.

| Токен                                                        | Назначение                                                                                           |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| `background` / `card` / `surface-secondary` / `elevated`     | серый фон окна (grouped background) / белые блоки / шапки и вложенные области / диалоги              |
| `foreground` / `muted-foreground` / `tertiary-foreground`    | label / secondaryLabel (5.1:1) / только плейсхолдеры и неактивное                                    |
| `border` / `border-strong` / `input`                         | separator (полупрозрачный) / opaqueSeparator / граница поля (3.3:1, WCAG 1.4.11)                     |
| `fill`, `fill-secondary`, `fill-tertiary`, `fill-quaternary` | заливки контролов: серые кнопки, трек сегментов, поле поиска, выбираемые плашки                      |
| `primary` / `link`                                           | заливка главного действия (белый текст 5.3:1) / текстовый акцент — ссылки, значки сайдбара           |
| `selection`, `selection-muted`                               | выделенная строка списка (заливка акцентом) / неактивное выделение                                   |
| `success` `warning` `info` `delayed` `danger` `neutral`      | состояния; `-bg` и `-border` вычисляются через `color-mix` от карточки — работают в обеих темах      |
| `success-solid`                                              | заливка кнопки «успех» (в тёмной теме зелёный текста слишком светлый для белой подписи)              |
| `segment-thumb`                                              | бегунок сегментированного контрола                                                                   |
| `--map-*`                                                    | маркеры и линии карты; читаются из JS (`healthColors()`, `cssColor()`) — один источник для обеих тем |

Запрещено: градиенты, свечение, фиолетовый, «сырые» цвета палитры в компонентах. Цвет никогда не единственный носитель
смысла: у статуса всегда есть значок и текст.

## Типографика

Шрифт: `-apple-system, BlinkMacSystemFont, "SF Pro Text", "Inter Variable"…` — на устройствах Apple настоящий SF Pro,
на остальных Inter (кириллица, табличные цифры). Шкала меняется на 1024 px: iOS-размеры на узком экране, macOS — на широком.

| Роль                  | Утилита                            | Узкий / широкий экран                                           | Вес         |
| --------------------- | ---------------------------------- | --------------------------------------------------------------- | ----------- |
| Large Title           | `text-large-title`                 | 30 / 26 px                                                      | 700         |
| Title 1 / 2 / 3       | `text-title1..3`                   | 24·20·17 / 22·17·15                                             | 700·650·600 |
| Headline              | `text-headline`                    | 15 / 13                                                         | 600         |
| Body                  | `text-body`                        | 15 / 13                                                         | 400         |
| Callout / Subheadline | `text-callout`, `text-subheadline` | 14·13 / 12·12                                                   | 400         |
| Footnote / Caption    | `text-footnote`, `text-caption`    | 12·11 / 11·11                                                   | 400         |
| Заголовок группы      | `text-section`                     | footnote, 600, вторичный цвет, обычный регистр                  | 600         |
| Сводная цифра         | `text-figure`                      | title1, табличные цифры                                         | 600         |
| Числа / номера        | `num`, `tabular`, `id-code`        | табличные цифры; `id-code` — перечёркнутый ноль (`CF-O-000002`) | —           |

Поля ввода — 16 px на телефоне (без автозума iOS). UPPERCASE-надписей нет. Новые классы ролей зарегистрированы
в `cn()` (`src/lib/utils.ts`), иначе tailwind-merge выбросит `text-body` рядом с `text-foreground`.

## Материалы, линии, радиусы, тени

- Материалы (`material-sidebar`, `material-bar`, `material-menu`) — только сайдбар, тулбар, таб-бар, меню, поиск,
  баннеры и плавающая панель действий. При `prefers-reduced-transparency` и без `backdrop-filter` — непрозрачные.
- Волосяные линии: `hairline`, `hairline-t/b/l/r` (0.5 px на Retina); в списках — с отступом от начала текста
  (`[&>li+li_[data-row-content]]:hairline-t`).
- Радиусы: `xs` 4 · `sm` 6 (кнопки, поля) · `md` 8 (меню, сегменты) · `lg` 10 (блоки, списки) · `xl` 14 (диалоги) · `2xl` 20 (шиты, талон).
- Тени: у карточек и кнопок нет. `shadow-control` — push-кнопка macOS и бегунок, `shadow-menu` — меню, поповеры, карта,
  `shadow-dialog` — диалоги и шиты.

## Движение

Кривая iOS `cubic-bezier(0.32, 0.72, 0, 1)`, 100 / 200 / 340 мс, выход 160 мс, без перелёта. Кнопки при нажатии
затемняются (а не уменьшаются), меню появляются из точки вызова (scale 0.96), диалоги — scale 1.04 → 1, шиты выезжают,
страницы проявляются (180 мс). `prefers-reduced-motion: reduce` — всё мгновенно, смысл сохраняется значками и текстом.

## Правила, которые нельзя нарушать

- Бизнес-логика, API и права при правках интерфейса не меняются.
- Все `data-testid` и доступные имена (подписи полей, тексты кнопок, `h1`, `role="dialog"`, нативные `<select>`) сохраняются — на них опираются E2E.
- Тексты интерфейса — в `src/lib/i18n/messages/ru.ts`; интерфейс только на русском.
- Без эмодзи-флагов (на Windows они превращаются в буквы) — рядом с городом пишется код страны.

# CargoFlow Design System

Направление (UI/UX Pro Max, `logistics operations console`, density 8 / motion 3): **Minimalism & Swiss Style** —
navy + trust blue, плотная спокойная типографика, цвет только со смыслом, движение только для объяснения изменений.
Источник истины — `src/app/globals.css` (токены) и `src/components/**` (компоненты).

## Цвета (семантические токены)

| Токен                                                                                | Назначение                                                                                   |
| ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| `background` / `foreground`                                                          | фон страницы / основной текст                                                                |
| `card` (`surface`), `surface-secondary`, `muted`                                     | карточки; вложенные панели и шапки таблиц; нейтральные подложки                              |
| `muted-foreground`                                                                   | вторичный текст (6.4:1 на белом)                                                             |
| `border`, `border-strong`, `input`                                                   | разделители; hover интерактивных карточек; границы полей (3.3:1 — WCAG 1.4.11)               |
| `primary` / `primary-hover`                                                          | главное действие, ссылки, текущий этап                                                       |
| `secondary(-hover)`, `accent`                                                        | второстепенные кнопки; подсветка текущего элемента                                           |
| `destructive(-hover)`                                                                | опасные действия                                                                             |
| `success` / `warning` / `info` / `danger` / `neutral` (+ `-bg`, `-border`)           | статусы: завершено / требует действия / в процессе / ошибка-спор / не начато (текст ≥ 4.5:1) |
| `sidebar`, `sidebar-foreground`, `sidebar-muted`, `sidebar-active`, `sidebar-accent` | навигация (navy)                                                                             |
| `rating`                                                                             | только заливка звёзд                                                                         |
| `overlay`                                                                            | подложка диалогов и панелей                                                                  |

Правило: в компонентах нет «сырых» цветов палитры (`bg-slate-*`, `hover:bg-red-700` и т. п.) — только токены.
Цвет никогда не единственный носитель смысла: у статуса всегда есть иконка и текст.

## Типографика

Шрифт — **Inter Variable** (`@fontsource-variable/inter`, кириллица, файлы в сборке — без внешних запросов).

| Роль                   | Утилита                        | Размер / строка                                    | Вес |
| ---------------------- | ------------------------------ | -------------------------------------------------- | --- |
| Display                | `text-display`                 | 30 / 36                                            | 650 |
| H1 (страница)          | `text-h1` (`PageHeader`)       | 22 / 30 → 24 / 32 с 640 px                         | 650 |
| H2 (секция)            | `text-h2`                      | 17 / 24                                            | 600 |
| H3 (карточка)          | `text-h3` (`CardTitle`)        | 15 / 22                                            | 600 |
| H4                     | `text-h4`                      | 13 / 20                                            | 600 |
| Body / Body small      | `text-sm` / `text-[0.8125rem]` | 14 / 20; 13 / 20                                   | 400 |
| Caption                | `text-caption`, `text-xs`      | 12 / 16                                            | 400 |
| Overline / label групп | `text-overline`                | 11 / 16, uppercase, +0.06em                        | 600 |
| Числа                  | `num`                          | табличные цифры                                    | —   |
| Номера документов      | `id-code`                      | табличные + перечёркнутый 0 (`CF-O-000002`: 0 ≠ O) | —   |

Поля ввода — 16 px на мобильном (без автозума iOS), 14 px с 640 px.

## Отступы, сетка, контейнеры

- Шкала 4 px (Tailwind): внутри карточки 16–20 px (`p-4`/`p-5`), между карточками 12–20 px (`gap-3`–`gap-5`), между секциями 24 px (`space-y-6`).
- Контейнеры: `max-w-page` (1400 px, рабочая область), `max-w-form` (832 px), `max-w-prose` (672 px).
- Брейкпоинты: mobile < 640, tablet 640–1023 (`sm`, `md`), laptop 1024–1279 (`lg` — появляется сайдбар), desktop 1280–1535 (`xl` — боковые колонки), large ≥ 1536 (`2xl`).
- Таблицы используют **container queries** (`hideBelow: "@3xl"` и т. п.): второстепенные колонки скрываются по ширине самой таблицы, а не окна.

## Радиусы

`sm` 6 px — чипы, счётчики · `md` 8 px — кнопки, поля, пункты меню · `lg` 10 px — элементы внутри карточек, меню, плитки иконок ·
`xl` 12 px — карточки, диалоги, панели · `2xl` 16 px — мобильные нижние панели · `full` — бейджи статусов, аватары.

## Тени (уровни, не украшение)

`shadow-xs` — карточка в покое · `shadow-sm` — кнопки/контролы карт · `shadow-md` — поповеры, hover интерактивной карточки ·
`shadow-lg` — диалоги · `shadow-xl` — боковые панели.

## Motion

| Токен                 | Значение                            | Где                                              |
| --------------------- | ----------------------------------- | ------------------------------------------------ |
| `--duration-micro`    | 120 мс (в классах — `duration-150`) | hover, focus, нажатие, иконки                    |
| `--duration-standard` | 200 мс                              | dropdown, tooltip, карточки, сворачивание меню   |
| `--duration-complex`  | 320 мс                              | диалоги, боковые панели, смена статуса/прогресса |
| `--duration-exit`     | 150 мс                              | выход ≈ 60–70 % входа                            |
| `--ease-out`          | `cubic-bezier(0.22, 1, 0.36, 1)`    | появление                                        |
| `--ease-in`           | `cubic-bezier(0.4, 0, 1, 1)`        | исчезновение                                     |

Анимации (`animate-*`): `fade-in/out` (оверлеи), `pop-in/out` (меню, подсказки — от точки вызова), `dialog-in/out`
(подъём 8 px + scale 0.98), `sheet-in/out-{right,left,bottom}`, `rise-in` (появление элементов списка со сдвигом
30–40 мс, ошибки полей), `page-in` (переход страницы 220 мс, `template.tsx`), `progress-grow` (заполнение прогресса
маршрута), `check-pop` (подтверждение — чекбокс, новый счётчик уведомлений), `live-pulse` (статус «в движении» —
только в крупном бейдже и текущем этапе, не в списках), `skeleton` (шиммер).

Принципы: анимируются только `transform`/`opacity`/цвета; кнопки — `active:scale-[0.98]`; движение происходит при
реальном изменении данных. **`prefers-reduced-motion: reduce`** — все длительности ≈ 0, бесконечные анимации
останавливаются; состояния остаются понятными без движения (иконка + текст).

## Статусы перевозки

Реальные статусы `OrderStatus` (не менялись). Визуально сгруппированы в фазы (`ORDER_PHASE_LABELS`):
Подготовка (выбор перевозчика → договор → машина → водитель) → Загрузка → В дороге (в пути, граница, таможня) →
Доставка → Завершена; отдельно — Приостановлена (спор, пауза) и Отменена.
Тон: `info` — в процессе, `warning` — требуется действие (договор, назначение, подтверждение доставки),
`success` — закрыта, `danger` — спор/отмена/пауза, `neutral` — черновик.

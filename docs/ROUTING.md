# Маршруты, километраж и карты

## Что считается

У каждого груза (`Load`) хранится маршрут по его точкам (`LoadStop`):

| Поле                                  | Что это                                                                          |
| ------------------------------------- | -------------------------------------------------------------------------------- |
| `routeDistanceKm`, `routeDurationMin` | километраж и время в пути (без отдыха водителя и границ)                         |
| `routeGeometry`                       | линия `[lng, lat][]`, упрощённая (Дуглас — Пекер) до ≤ 500 точек                 |
| `routeSource`                         | `PROVIDER` — маршрут грузовика по дорогам; `ESTIMATE` — оценка «по прямой × 1.2» |
| `routeProvider`, `routeComputedAt`    | кто и когда посчитал                                                             |
| `routeStopsHash`                      | хеш координат точек: совпал — пересчёт не нужен                                  |

Перевозка (`TransportOrder`) берёт маршрут своего груза. Километраж показывается в предпросмотре мастера груза,
карточке груза, на бирже (список и карточка), в карточке перевозки и у водителя. Оценка подписывается «≈ 1 240 км (оценка)».
Карты (груз, перевозка, операции, автопарк) рисуют линию по дорогам; если её нет — прямые между точками, как раньше.

## Как считается

1. **Координаты точек** (`src/server/geo/geocoding.ts`): указанные пользователем → справочник городов
   (`src/lib/geo/geocoder.ts`) → кэш `GeocodeCache` → Geoapify Geocoding API (фильтр страны). Если заданы улица/дом —
   сначала ищется адрес, при неудаче — город. Найденное и «не найдено» (на 30 дней) пишется в кэш.
2. **Маршрут** (`src/lib/geo/routing.ts` → `computeRoute`): Geoapify Routing API, `mode=truck`, все точки одним запросом.
   - ошибка провайдера (нет ключа, сеть, таймаут 8 с, лимит) — оценка всего маршрута, без повторных запросов;
   - «маршрут не найден» (например, сегмент через закрытую границу с Китаем) — по сегментам: найденные — по дорогам,
     не найденный — оценка; итог помечается `ESTIMATE`.
3. Пересчёт — при создании груза и при изменении точек (`load.service.ts`), только если изменился хеш координат.
   Внешние HTTP-запросы выполняются **до** транзакции с `SELECT … FOR UPDATE`.

Ошибки провайдера логируются (`geoapify.*`, `route.*`) и наружу не пробрасываются: груз сохраняется всегда.

## Переменные

| Переменная                  | Где                               | Зачем                                                                                       |
| --------------------------- | --------------------------------- | ------------------------------------------------------------------------------------------- |
| `GEOAPIFY_API_KEY`          | только сервер                     | маршруты и геокодирование. Пусто — справочник и оценка                                      |
| `NEXT_PUBLIC_GEOAPIFY_KEY`  | браузер (встраивается при сборке) | подложка карт, стиль `positron`. Отдельный ключ, ограничьте его доменом в кабинете Geoapify |
| `NEXT_PUBLIC_MAP_STYLE_URL` | браузер                           | свой стиль MapLibre, приоритетнее ключа Geoapify                                            |

Без ключей подложки — тайлы `tile.openstreetmap.org`: только для разработки (политика OSM запрещает продакшен-нагрузку).
CSP (`next.config.ts`) уже пропускает стиль, тайлы, шрифты и спрайты Geoapify: `connect-src https:`, `img-src https:`.

## Досчёт маршрутов для существующих грузов

```bash
npm run routes:backfill -- --mode real --dry-run     # сколько грузов без маршрута
npm run routes:backfill -- --mode real               # досчитать (батчи по 20, пауза 3 с)
npm run routes:backfill -- --mode demo --estimate    # без сети: записать оценку
npm run routes:backfill -- --mode real --force       # пересчитать все (например, после подключения ключа)
```

Параметры: `--batch`, `--pause` (мс), `--max-requests` (по умолчанию 2500 — бесплатный тариф Geoapify 3000 запросов
в сутки). Бюджет проверяется перед каждым грузом с запасом на худший случай; при исчерпании скрипт останавливается —
повторный запуск продолжит с необработанных грузов. Скрипт проверяет метку схемы (`npm run db:migrate:all`).
Сиды (`prisma/seed*.ts`) в сеть не ходят и пишут оценку.

## Навигаторы водителя

`src/lib/geo/navigators.ts` (веб) и `native/packages/cargoflow_core/lib/src/domain/navigators.dart` (приложение):

| Навигатор | Приложение                                                                                                   | Веб                                                                             |
| --------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------- |
| Яндекс    | `yandexnavi://build_route_on_map?lat_to=…&lon_to=…` → `yandexmaps://maps.yandex.ru/?rtext=~lat,lon&rtt=auto` | `https://yandex.ru/maps/?rtext=~lat,lon&rtt=auto`                               |
| 2ГИС      | `dgis://2gis.ru/routeSearch/rsType/car/to/lon,lat` (**lon,lat**)                                             | `https://2gis.ru/routeSearch/rsType/car/to/lon,lat`                             |
| Google    | iOS: `comgooglemaps://?daddr=lat,lon&directionsmode=driving`                                                 | `https://www.google.com/maps/dir/?api=1&destination=lat,lon&travelmode=driving` |

Без координат передаются адрес и город (поиск). Приложение водителя запоминает последний выбор и предлагает его первым.

## Не сделано (следующий этап)

- Next Load и топливо считают расстояния по-прежнему (оценка) — подключить `RoutingProvider`.
- Параметры грузовика (габариты, вес, ADR, платные дороги) провайдеру не передаются.
- Автокомплит адреса в мастере груза.

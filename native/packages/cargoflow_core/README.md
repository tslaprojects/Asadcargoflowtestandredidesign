# cargoflow_core

Общее ядро нативных приложений CargoFlow: API-клиент (Bearer-токен, конверт ответа, офлайн-ошибки), сессия и режим данных, модели, статусы и этапы рейса, тема (токены дизайн-системы), общие виджеты (карта, этапы, документы, вход).

См. [docs/NATIVE_APPS.md](../../../docs/NATIVE_APPS.md).
